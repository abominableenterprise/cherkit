telemetry: added

- Added the optional `CherKitTelemetryFirebase` Swift product for Crashlytics errors/crashes and iOS Performance spans, compatible with Firebase 11.x through 13.x. Automatic network instrumentation defaults off. Apps must call `try FirebaseTelemetryBackend.prepareForConfiguration()` before every Firebase configuration to reset persisted Performance overrides. Crashlytics automatic uploads stay disabled; reports are explicitly submitted only after current consent/build gates pass.
- Added a defaulted `TelemetryBackend.update(restricted:)` hook so adapters can synchronize errors-only sessions without breaking existing implementations. A failed restriction update stops active collection; every start or restart requires a successful update. Apps must configure Firebase startup privacy defaults; see the adapter setup guide for SDK revocation limits and dSYM upload instructions.
